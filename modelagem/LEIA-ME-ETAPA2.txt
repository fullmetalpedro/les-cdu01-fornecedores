CONTEUDO

2. Script DDL                       banco/01-ddl.sql
3. Script de dominios (RNF0013)     banco/02-dominios.sql
4. Diagrama de classes de dominio   modelagem/diagramas/classes.png
5. Classes de dominio               backend/Fornecedores.Dominio/

A pasta docs/ traz a especificacao do caso de uso, o DRS e o contrato de
integracao da Etapa 1, citados pelos documentos acima.

COMO CRIAR O BANCO
------------------
Execute os dois scripts em ordem, num banco PostgreSQL vazio:

  psql -d <banco> -f banco/01-ddl.sql -f banco/02-dominios.sql
